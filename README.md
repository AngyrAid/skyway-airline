# SkyWay — учебный проект сайта авиакомпании

## О проекте
Одностраничный адаптивный сайт вымышленной авиакомпании. Сделан на HTML, CSS и JavaScript без сборщиков и внешних библиотек.

## Как открыть
1. Распакуй папку проекта.
2. Открой её в Visual Studio Code.
3. Открой `index.html` в браузере или запусти через расширение Live Server.

## Что реализовано
- Адаптивная навигация для мобильных устройств.
- Демонстрационная форма поиска рейсов.
- Перестановка городов местами.
- Проверка даты вылета.
- Демонстрационная форма подписки.
- Метатеги, `robots.txt` и `sitemap.xml`.

## Перед публикацией
1. Замени `YOUR-USERNAME` в `robots.txt` и `sitemap.xml` на своё имя GitHub.
2. Проверь сайт на телефоне и компьютере.
3. Учитывай, что фотографии загружаются с Unsplash и для их отображения нужен интернет.
4. Формы демонстрационные: данные не отправляются на сервер.

## Важно
SkyWay — вымышленная компания, а маршруты и цены являются примером для учебной работы.
