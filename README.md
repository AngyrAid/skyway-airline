# SkyWay — учебный многостраничный сайт авиакомпании

SkyWay — вымышленный бренд. Поиск рейсов, цены, подписка и контактная форма демонстрационные: сайт не бронирует билеты и не отправляет данные на сервер.

## Файлы
- `index.html` — главная страница и форма поиска рейса.
- `destinations.html` — города Сочи, Казань и Санкт-Петербург.
- `about.html` — концепция и принципы SkyWay.
- `contacts.html` — форма обратной связи и частые вопросы.
- `style.css` — единый адаптивный дизайн.
- `script.js` — мобильное меню и формы.
- `robots.txt`, `sitemap.xml` — базовые SEO-файлы.

## Открытие
Распакуйте архив, откройте папку в Visual Studio Code и откройте `index.html` в браузере. Для удобства можно использовать расширение Live Server.

## GitHub Pages
Загрузите все файлы в корень репозитория. В GitHub откройте Settings → Pages → Deploy from a branch, выберите `main` и `/(root)`, затем Save. Замените `YOUR-USERNAME` и `skyway-airline` в `robots.txt` и `sitemap.xml`, если логин или имя репозитория отличаются.

Фоновые изображения загружаются с Unsplash и требуют интернет-соединения. Если нужно хранить изображения в репозитории, скачайте их в `images/` и замените адреса в `style.css` локальными путями.
